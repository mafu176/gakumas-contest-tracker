# 学マス コンテスト戦績トラッカー

## 概要

学マス コンテスト戦績トラッカーは、学園アイドルマスターのコンテスト戦績を記録・分析・共有するためのツールです。

対戦結果、スコア、順位、編成、シーズン情報をまとめて管理できます。入力した戦績は自動で集計され、シーズンごとの勝率、日別戦績、編成変更履歴、ステージ別分析、相手メタ分析などを確認できます。

共有画像の作成にも対応しているため、シーズンの振り返りや戦績共有にも利用できます。

## 主機能

- OCR入力
- シーズン管理
- 編成管理
- 分析
- 共有画像
- 統計データ送信

## 利用の流れ

おすすめの利用順は次のとおりです。

```text
シーズン
↓
編成
↓
入力
↓
分析
↓
共有
```

まずシーズンを作成し、よく使う編成を登録します。その後、入力タブで対戦結果を保存し、分析タブや共有タブで戦績を確認します。

## セットアップ

ローカルで起動する場合は、次の手順で実行できます。

```bash
npm install
npm run dev
```

ビルド確認は次のコマンドで行います。

```bash
npm run build
```

## バックアップ

戦績データはブラウザ内に保存されます。端末変更、ブラウザ変更、キャッシュ削除などに備えて、定期的なバックアップをおすすめします。

設定タブから JSON 形式でバックアップを書き出せます。復元すると、対戦履歴、シーズン、編成テンプレート、分析条件、プレイヤー名などを戻せます。

大規模な更新前や端末変更前は、必ずバックアップを作成してください。

## 統計データ送信

設定タブの「統計データ送信」を有効にすると、環境分析・利用状況確認・運営改善用データの送信に協力できます。

送信される主な内容は、対戦結果、編成情報、プレイヤー名（任意）、アプリバージョン、送信日時などです。

相手名、メモ、バックアップデータなどは送信されません。

プレイヤー名は任意入力です。未入力でもツールは利用できます。統計データ送信はいつでも設定タブから切り替えできます。

## Google Sheets / Apps Script

統計データ送信では、Google Apps Script の Web App に JSON payload を送信し、Google Sheets に記録する構成を想定しています。

schemaVersion 2 の payload では、`matches` シートと `stage_members` シートに分けて保存する想定です。既存の対戦履歴を編集した場合は、同じ `match_id` の行を更新し、ステージメンバー情報は差し替える運用を推奨しています。

Apps Script 側の受け取り仕様は、`docs/gas-anonymous-stats-v2.md` を参照してください。

## 注意事項

- このツールは非公式の個人制作ツールです。
- OCR の読み取り結果は必ず確認してください。
- ブラウザの保存データを削除すると、ローカルの戦績データも消える場合があります。
- 重要なデータは定期的にバックアップしてください。
- 共有画像や投稿文の内容は、投稿前に確認してください。
- 仕様変更や表示変更により、今後のアップデートで画面や項目が変わる場合があります。
