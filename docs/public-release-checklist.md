# Public Release Checklist

## Build Check

- [ ] `npm run build` が成功する
- [ ] ビルド時に致命的な warning が出ていない

## OCR Check

- [ ] 通常結果画面の OCR が動作する
- [ ] ハイスコア画面の OCR が動作する
- [ ] next-screen は対象外メッセージになる
- [ ] OCR 後の確認画面で値を編集できる
- [ ] OCR 取込後に保存できる

## Input / Save Check

- [ ] 対戦相手を入力できる
- [ ] 位置を選択できる
- [ ] 獲得 pt を入力できる
- [ ] ステージ勝敗を入力できる
- [ ] 保存後に履歴へ追加される
- [ ] 保存後に集計値が更新される

## Edit / Update Check

- [ ] 既存履歴を入力欄へ読み込める
- [ ] 編集後に同じ履歴として更新される
- [ ] 更新時に新しい match id が作成されない
- [ ] 削除確認モーダルが表示される
- [ ] 履歴を削除できる

## Season Flow Check

- [ ] シーズンを新規作成できる
- [ ] シーズン名、期間、最終 pt、順位を保存できる
- [ ] 分析対象シーズンを変更できる
- [ ] シーズンサマリーが表示される
- [ ] 日別戦績が表示される
- [ ] 編成変更履歴が表示される
- [ ] シーズンの編集、複製、削除ができる

## Formation Template Check

- [ ] 自分編成を選択できる
- [ ] 相手編成を選択できる
- [ ] 編成テンプレートを保存できる
- [ ] 保存したテンプレートを読み込める
- [ ] テンプレートを削除できる

## Analysis Tab Check

- [ ] 分析条件を保存できる
- [ ] 保存した分析条件を読み込める
- [ ] ステージ別アイドル分析が表示される
- [ ] ステージ別アイドル分析でアイコンが表示される
- [ ] 相手メタ分析が表示される
- [ ] 相手メタ分析でアイコンが表示される
- [ ] 位置別サマリーが表示される
- [ ] 勝率グラフが表示される
- [ ] 最終編成分析が表示される

## Share Image Check

- [ ] 共有タブが開ける
- [ ] 共有対象シーズンを選択できる
- [ ] 横長（1.91:1）が表示される
- [ ] 正方形（1:1）が表示される
- [ ] スマホ縦（9:16）が表示される
- [ ] PNG 保存ができる
- [ ] PNG コピーができる
- [ ] 共有カードの画像比率が崩れていない
- [ ] プレイヤー名（任意）が共有カードへ反映される

## X Post Text Check

- [ ] X 投稿ボタンが動作する
- [ ] 投稿文プレビューが表示される
- [ ] ハッシュタグが `#学マスコンテスト戦績トラッカー` になっている
- [ ] PNG 添付案内が表示される

## Statistics Data Sending Check

- [ ] 統計データ送信 OFF で送信されない
- [ ] 統計データ送信 ON で新規保存時に送信される
- [ ] 統計データ送信 ON で編集保存時にも送信される
- [ ] `client_id` が送信される
- [ ] `app_version` が送信される
- [ ] `sent_at` が送信される
- [ ] `display_name` が送信される
- [ ] 相手名、メモ、バックアップデータが送信されない

## Backup Export / Import Check

- [ ] バックアップを書き出せる
- [ ] バックアップを復元できる
- [ ] 対戦履歴が復元される
- [ ] シーズンが復元される
- [ ] 編成テンプレートが復元される
- [ ] 分析条件が復元される
- [ ] プレイヤー名（任意）が復元される
- [ ] 共有カード設定が復元される

## Mobile Layout Check

- [ ] スマホ幅でタブが操作できる
- [ ] 入力フォームが崩れていない
- [ ] OCR 取込 UI が操作できる
- [ ] 履歴カードが読みやすい
- [ ] シーズン一覧が操作できる
- [ ] 分析テーブルが横スクロールできる
- [ ] 共有カードプレビューが確認できる

## Privacy Wording Check

- [ ] 設定タブの統計データ送信説明が最新になっている
- [ ] ガイドの統計データ送信説明が最新になっている
- [ ] プレイヤー名（任意）が任意入力であることが分かる
- [ ] 相手名、メモ、バックアップデータを送信しない説明がある

## Google Sheets / Apps Script Check

- [ ] GAS Web App URL が正しい
- [ ] 新規 payload が `matches` に追加される
- [ ] 編集 payload が同じ `match_id` の行を更新する
- [ ] `stage_members` は同じ `match_id` の古い行を削除してから再追加される
- [ ] `client_id` 列が存在する
- [ ] `app_version` 列が存在する
- [ ] `sent_at` 列が存在する
- [ ] `display_name` 列が存在する
- [ ] 旧 payload でもエラーにならない
- [ ] AdminDashboard の合計が編集保存で重複増加しない
