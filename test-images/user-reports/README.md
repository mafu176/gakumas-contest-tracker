# OCR検証画像管理

このフォルダは、ユーザーから提供されたOCR検証画像を管理するための場所です。

OCR成功・失敗を問わず保存します。

## unreviewed

未確認画像。

まだOCR確認を行っていない画像を保存します。

## passed

OCR結果が正常だった画像。

精度確認用サンプルとして保持します。

## failed

OCR誤認が確認された画像。

後日修正対象になります。

## fixed

OCR修正・回帰テスト追加まで完了した画像。

## 運用

1.
ユーザーから画像を受け取る

2.
unreviewed に保存する

3.
OCR結果を確認する

4.
成功:
passed へ移動

5.
失敗:
failed へ移動

6.
OCR修正・回帰追加後:
fixed へ移動

## Notes

- 成功画像も削除しない
- 高スコア画像は重要サンプル
- OCR改善時は回帰テストへ追加する
- 実戦画像を優先する
